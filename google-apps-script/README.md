# Google Sheets SIM-BHP

1. Buka Spreadsheet SIM-BHP.
2. Ekstensi -> Apps Script.
3. Buka `Code.gs` pada folder ini, salin seluruh isinya ke Apps Script.
4. Simpan.
5. Deploy -> New deployment -> Web app.
6. Execute as: Me.
7. Who has access: Anyone.
8. Salin URL `/exec`.
9. Buka SIM-BHP -> Pengaturan -> Google Sheets & Hosting, tempel URL tersebut -> Simpan URL.

Setelah URL tersimpan, setiap tambah/edit/hapus Master BHP, Penerimaan, dan Pengeluaran akan otomatis dikirim ke Google Sheets.
